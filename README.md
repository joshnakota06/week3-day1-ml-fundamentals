# Machine Learning Fundamentals Challenge

## Objective

Build a Linear Regression model to predict student marks using:

- Study Hours
- Attendance
- Assignments

---

## Technologies Used

- Python
- Pandas
- NumPy
- Scikit-Learn
- Plotly

---

## Project Workflow

1. Dataset Exploration
2. Feature Selection
3. Train-Test Split
4. Model Training
5. Predictions
6. Evaluation
7. Data Visualization

---

## Evaluation Metrics

- Mean Absolute Error (MAE)
- R² Score

---

## Visualizations

- Study Hours vs Marks
- Attendance vs Marks
- Assignments vs Marks
- Regression Line Visualization
- Predicted Marks Trend
